# Script Craft Inspiration (study notes)

Patterns distilled for Jugal’s 45–55s vibe-coding reels. Steal structure — never paste someone else’s script.

Sources: short-form virality craft (outlier hooks + own meat), timed Reel storytelling (rehook/stakes/struggle), authenticity/quirks. Living Voice Card still wins on spoken identity.

---

## Triple hook (first ~3 seconds)

Optimize all three together — scroll-stop fails if one is weak:

1. **Verbal** — `opening_line` / first spoken sentence. Instantly clear (5-year-old test). Named tool when possible.
2. **Written** — `title_overlay` (and on-screen text). Short, high-contrast; completes or deliberately incomplete the verbal hook.
3. **Visual** — `hook_visual` + first capture. Real Cursor/Claude UI or face+proof. Never abstract AI brains.

If verbal says “Cursor was billing me twice,” written should punch that claim and visual should show settings/bill — not a neon network.

---

## Viral hook + your meat (non-negotiable)

- Model **outlier** first lines, formats, and topics (videos that beat an account’s average — not random tips).
- Fill the **body** with Jugal’s expertise: one copyable move + receipt.
- Copying a whole viral reel = fraud energy. Hook pattern yes; their unique jokes/lines no.
- Prefer proven containers: FACE_HOOK_SCREEN_PROOF, WALKTHROUGH, CONFESSION_STAT — don’t invent a new format every script.

---

## Broad hook → niche value

- Open wide enough that strangers stop (“AI burned my bill,” “Claude kept forgetting my stack”).
- Then narrow to the specific tool path (Settings → Models → toggle; CLAUDE.md in root).
- CTA can be niche (try this today / follow for the series). Don’t niche the *first line* so hard that only five people care.

---

## Rehook + stakes (~5–10s)

After the open, plant conflict before the teach:

- “But here’s the thing…” / cost / wrong assumption / withheld payoff.
- Maps to `open_loop_plant` + crust beat (`here's the thing`, etc.).
- Viewer must need the middle to resolve the tension.

---

## Struggle before receipt

Educational scripts still need one friction beat:

Tried → broke / wasted / felt stupid → one move → receipt.

Story scripts (~20% of mix: CONFESSION/BUILD): vulnerability + clear payoff. Educational (~80%: HACK/TIP/NEWS): actionable meat, zero fluff.

Fluff = vague advice with no screen-copyable step. Kill it.

---

## Read-aloud + anti-AI trust

- Scripts are relationships at scale. Robotic ChatGPT cadence drains the trust battery.
- Read every line aloud. If you stumble, cut.
- Taste and filming stay human. AI helps structure; it does not replace personality.

---

## Quirk lean (Jugal unfair advantages)

Lean harder into what only he has:

- Designer who learned to ship with AI — surprise that it works
- Third-language clarity — short punches, no essay clauses
- Practitioner screens — show the toggle/file, don’t lecture theory

Sharp edges beat beige “helpful tips” energy.

---

## Hard checklist before a script ships

- [ ] Verbal + written + visual hooks align in the first 3s
- [ ] Hook could stop a stranger; meat is niche-specific and copyable
- [ ] Rehook/stakes before the teach
- [ ] One struggle beat before the receipt
- [ ] No Step one/two/three stacks; no corporate tells
- [ ] Edit recipe matches format (face→screen for hacks)
