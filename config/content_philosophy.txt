CONTENT PHILOSOPHY — vibe coding / AI coding tools

PRIMARY GOAL: Weekly tips, tricks, hacks, builds, and actionable news that builders
can try in the next 10 minutes. Viewer thinks: "I'm opening Cursor/Claude Code right now."

HOME NICHE (not a prison — series rotate inside this world):
Cursor, Claude Code, tokens/cost, agents/MCP, vibe coding, shipping hacks, tool mashups
(e.g. Claude Code + Higgsfield, Cursor + MCP).

SERIES FIRST:
Every script belongs to the active series arc (2–3 weeks) unless it is a journal exception.
Stamp series_note like "Cursor Deep · Ep 3/6". Off-arc fillers: max 1 per batch.

WEEKLY FRESHNESS:
Prefer seeds from the last 7 days (changelog, Reddit/HN thread, new MCP, pricing change).
Series = lens. Weekly = what's hot inside that lens.

SCRIPT MIX (8 per batch, journal fills first):
- 3 × HACK — one concrete combo (tool A + tool B → outcome)
- 2 × TIP — one setting, shortcut, prompt pattern, or config detail
- 1 × BUILD — micro ship story / what you made this week
- 1–2 × ACTIONABLE_NEWS — changelog or viral thread with "do this today"
- 0–1 × CONFESSION — token overspend, agent fail, vibe-coding theater

FORMAT RULES:
- Named tools in the hook. Concrete action in the middle. Receipt at the end ($, minutes, file).
- Prefer tip/hack/confession voice over "Step one / Step two / Step three" listicles.
- One copyable move beats three vague career steps.
- Mashups encouraged when true (Claude Code + Higgsfield, Cursor rules + MCP, etc.).

PERSONAL WORK:
- Default: ZERO sentences about employer internal systems
- Journal scripts: preserve the creator's personal angle from the ramble
- OK lightly: SaaS/side builds, Cursor/Claude spend, shipping with AI tools

CREDIBILITY:
Use creator_takes for opinions. Use work_patterns sparingly and generalized.
Never invent first-person war stories.

HOOK STYLE (steal patterns from Alex Finn / Chris Raroque / Fireship energy — not their voice):
- "Claude Code can call Higgsfield and spit the product render while it writes the page."
- "I overspent on Cursor again — and the setting that fixed it took ten seconds."
- "Everyone's vibe coding. Here's the one habit that makes it actually ship."

STORYTELLING RHYTHM:
Claim → one move → receipt. Alternate sentence length. One feeling word when it fits.
Every piece answers: "What do I try in the next 10 minutes?"
