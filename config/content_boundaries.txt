CONTENT BOUNDARIES — HARD RULES (non-negotiable)
Creator: Jugal Sheth, senior AI data engineer, NYC, visa pathway.
Niche: AI coding tools & vibe coding (Cursor, Claude Code, tokens, agents, MCP, hacks).

NEVER MENTION IN ANY SCRIPT:
- Job searching, interviewing, "in my interviews this year", offer negotiations while job-hunting
- Current employer drama, complaints about coworkers, or anything colleagues could misread
- Immigration, visa status, green card, politics, geopolitics, government criticism
- Fake research claims ("I analyzed 200 job posts") unless literally true with proof
- Niche internal work stories (currency requests, PO tools, vendor admin flows, etc.)
- Invented first-person stories — optional generalized lines only from work_patterns.txt (max 1 sentence)

AUDIENCE:
Builders shipping with AI tools — juniors through seniors, indie builders, practitioners.
Write so a junior can try the tip Monday AND a power user respects the stack detail.

MONDAY VALUE:
Viewer should want to OPEN the tool after watching — and have 1 concrete action.
Show building energy; don't position as someone exploring other jobs.

PERSONAL PROJECTS (use sparingly):
- OK: built with Claude/Cursor, users shipped, token bills, MCP mashups

- Frame as proof of builder craft, not self-promotion

- HACK: tool A + tool B → outcome (e.g. Claude Code + Higgsfield)
- TIP: one setting/shortcut/config
- BUILD: micro ship story
- ACTIONABLE_NEWS: changelog/thread + "do this today"
- CONFESSION: spend/fail/theater → lesson
- Prefer hook_type CONFESSION or OPEN LOOP for confession/hack scripts

BANNED HOOK PATTERNS (overused, feel like templates):
- "Here's what's wild" (max 1 per 10 scripts)
- "I analyzed N job posts/resumes"
- "If you've ever wondered..."
- "In this video"
- "Hey guys"
- Three consecutive sentences starting with "Step one", "Step two", "Step three"
- Hiring-manager listicles ("5 skills hiring managers want") unless journal-sourced
- Generic "learn AI" without a named tool stack
